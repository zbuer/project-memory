1. 运行 skill 内 `scripts/ensure-memory.sh --with-charter`（确保 `.memory/` 与 `CHARTER.md` 模板存在）。

4. 更新章程内「变更记录」。  
5. 向用户确认：文件路径 + 「目的」段摘要。
